DIVINE HAIR YV COLLECTION — VERSION BOUTIQUE
==============================================

Cette version est conçue pour GitHub Pages.

CONTENU
- index.html : boutique complète
- assets/divine-hair-logo.jpg : logo/identité
- assets/divine-hair-brand.jpg : visuel de marque
- assets/product-01 à product-45 : photos extraites du catalogue fournisseur
- Les prix affichés sont calculés automatiquement : prix fournisseur × 2,5.

IMPORTANT
Le panier et la préparation de commande sont fonctionnels côté navigateur.
Le paiement carte réellement encaissé n'est PAS encore branché : il faudra connecter
un prestataire marchand (Stripe, PayPal, Mollie, Alma, etc.) avec vos propres liens/compte.

GITHUB PAGES
1. Ouvrir le dépôt divinehairyvcollection.github.io
2. Remplacer l'ancien index.html par le nouveau index.html.
3. Envoyer le dossier assets/ entier.
4. Valider les modifications sur main.
5. GitHub Pages publiera automatiquement le site.

ORIGINES
Les références du PDF n'indiquent pas l'origine Vietnam/Inde pour chaque produit.
Les produits ne sont donc pas attribués automatiquement à Vietnamese Hair ou Indian Hair.
Il faudra valider cette information avant de classer chaque référence.
